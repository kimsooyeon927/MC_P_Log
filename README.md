# P_Log (MC_final_project)

**아날로그 감성의 인생네컷을 모바일 앨범으로 관리하는 Android 애플리케이션**

친구, 가족, 연인 등 주변 사람들과 함께 찍은 **인생네컷 사진을 모바일에서 체계적으로 저장하고 관리**할 수 있도록 제작한 모바일 애플리케이션입니다.

실물 사진첩에 인생네컷을 모아두는 아날로그 감성을 모바일 환경으로 옮겨, 시간과 장소에 관계없이 사진과 함께 당시의 기록을 확인할 수 있도록 하는 것을 목표로 했습니다.

## 🎯 프로젝트 배경

최근 인생네컷, 포토이즘 등 즉석 사진 촬영 문화가 확산되면서 지인들과 함께 찍은 사진을 추억으로 보관하는 경우가 많아졌습니다.

하지만 실물 사진은 별도의 앨범이나 보관 공간이 필요하고, 사진이 많아질수록 원하는 사진을 다시 찾기 어렵다는 불편함이 있습니다.

이를 해결하기 위해 **인생네컷 사진을 모바일에서 앨범 형태로 관리하고, 사진에 날짜와 함께 찍은 사람 등의 정보를 기록할 수 있는 앱**을 기획했습니다.

## ✨ 주요 기능

### 1. 사진 앨범 관리

- 등록한 인생네컷 사진을 모바일 앨범 형태로 확인
- 사진과 함께 촬영 날짜 및 관련 정보를 관리
- 등록된 사진을 데이터베이스에 저장

### 2. 사진 정보 기록

사진과 함께 다음과 같은 정보를 기록할 수 있습니다.

- 📅 촬영 날짜
- 👥 함께 찍은 사람의 이름
- 📝 사진과 관련된 코멘트

### 3. 사진 검색

저장된 사진을 원하는 조건에 따라 검색할 수 있습니다.

- 이름으로 검색
- 날짜로 검색

### 4. 데이터베이스 기반 CRUD

사진과 사진에 대한 부가 정보를 데이터베이스로 관리하여

- 사진 및 정보 등록
- 저장된 정보 조회
- 정보 삭제
- 검색

등의 기능을 제공합니다.

## 📱 화면 구성

### 기본 앨범

- 등록 된 사진 게시

### 사진 등록

- 갤러리 연동을 통한 사진 등록

### 사진 검색

- 이름을 기준으로 검색
- 날짜를 기준으로 검색

## 🗂️ 데이터 구성

사진 한 장을 단순한 이미지로만 저장하지 않고, 다음 정보를 함께 관리하도록 설계했습니다.

| 데이터 | 설명 |
| --- | --- |
| Image | 인생네컷 사진 |
| Date | 사진 촬영 날짜 |
| Name | 함께 찍은 사람의 이름 |
| Comment | 사진에 대한 코멘트 |

이를 통해 단순한 사진 보관 앱이 아니라 **사진과 당시의 추억을 함께 기록하는 디지털 사진첩**을 구현하고자 했습니다.

## 🛠️ 주요 구현 내용

- 모바일 UI 구성
- Fragment를 활용한 화면 구성
- 동적 View를 활용한 사진 목록 구성
- QR 코드 기반 사진 등록
- 데이터베이스 설계 및 연동
- 사진 데이터 Insert / Delete
- 날짜 및 이름 기반 검색
- 앨범 형태의 사진 관리
